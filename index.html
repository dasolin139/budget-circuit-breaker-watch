오늘 Step1 상위 3개 재구성

  1. Agent control surface builder: reasoning interrupt, subagent trace, conditional approval, payload boundary를 한 번에 다루는 운영 제어면 도구
  2. Bedrock Responses rollout checklist: OpenAI Python/Node의 Bedrock Responses 공식 지원을 기준으로 멀티 provider 출시 체크리스트를 주는 도구
  3. Plugin skill shipping guard: Codex의 plugin skill qualified name 검증과 remote catalog cache 흐름에 맞춘 plugin shipping 체크 도구

오늘은 세 후보 중 1번이 가장 넓은 pain을 가장 짧은 시간에 공개 검증할 수 있다고 판단했습니다.

외부 근거

  • OpenClaw: oversized MCP body를 413으로 명시
  • LangChain: nested run을 run.subagents channel로 노출
  • LangChain: HumanInTheLoop에 interrupt_mode / when predicate 추가
  • llama.cpp: reasoning interruption control endpoint 추가
  • vLLM: reasoning + tool-call parser 통합
  • openai-python 2.40.0: Amazon Bedrock Responses 지원
  • Codex: plugin skill base name 검증
  • Codex: remote plugin catalog cache
