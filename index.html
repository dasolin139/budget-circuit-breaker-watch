왜 오늘 이 방향을 골랐나

  • Step1 상위 pain은 무음 hang, runaway cost, conversation state 오염이었습니다.
  • 외부 근거: Responses API silent hang, Agents SDK도 동일 hang, cache hit 40%→0% 급락, background=true 전부 server_error, 이전 질문 답변이 현재 턴에 나오는 상태 오염.
  • 전날의 generic watchdog보다 오늘은 “언제 자동으로 차단할지”와 “비용 이상을 incident로 볼지”를 더 직접 다룹니다.

즉, 감시 제품 전체가 아니라 먼저 운영자가 지금 세션을 멈출지, 롤백할지, 고객에게 뭐라고 말할지를 결정하는 아주 좁은 도구로 테스트합니다.
